\section{Perceptual Hash Audit Methodology}
Let $I_g(u, v)$ represent an 8-bit grayscale image downsampled to dimensions $M \times N$ with $M = 8, N = 9$. The difference hash vector $\mathbf{h} \in \{0, 1\}^{64}$ is computed via adjacent column comparison:
\begin{equation}
    \mathbf{h}[8u + v] = \mathbb{I}\Big( I_g(u, v) > I_g(u, v+1) \Big), \quad u \in [0, 7], v \in [0, 7]
\end{equation}
The distance matrix is clustered using disjoint set union (Union-Find) with path compression:
\begin{equation}
    \text{Cluster}(i) = \text{Cluster}(j) \iff D_H(\mathbf{h}_i, \mathbf{h}_j) \le \tau, \quad \tau = 8
\end{equation}
This operation isolated \nearDupGroups{} connected components encompassing \nearDupImages{} burst-shot images, guaranteeing complete cluster isolation during stratified partitioning.

\section{Reproducibility Checklist}
\begin{enumerate}
    \item \textbf{Random Seeds Fixed:} All random number generators (Python \texttt{random}, NumPy, PyTorch CPU and CUDA) seeded to 42 for primary benchmarks.
    \item \textbf{Deterministic CUDA Operations:} Enforced \texttt{torch.backends.cudnn.deterministic = True}.
    \item \textbf{Data Splits Manifest:} Explicit image path manifests preserved in \texttt{data/splits/train.csv}, \texttt{val.csv}, and \texttt{test.csv}.
    \item \textbf{ONNX Export Scripts:} Standalone conversion scripts verified against FP32 reference models.
\end{enumerate}
